# movie-emotion-arcs

## Dataset Acknowledgment

The dialogue and script data used in this project comes from the Film Corpus, which contains 862 film scripts collected from IMSDb. The corpus includes approximately 664,000 lines of dialogue across 7,400 characters. I use the corpus to construct a scene-level dialogue dataset for analyzing emotional arcs across movie genres.

The original corpus should be cited as:

- Walker, Marilyn A., Ricky Grant, Jennifer Sawyer, Grace I. Lin, Noah Wardrip-Fruin, and Michael Buell. “Perceived or Not Perceived: Film Character Models for Expressive NLG.” In *International Conference on Interactive Digital Storytelling (ICIDS)*, Vancouver, Canada, 2011.

- Walker, Marilyn A., Grace I. Lin, and Jennifer E. Sawyer. “An Annotated Corpus of Film Dialogue for Learning and Characterizing Character Style.” In *Proceedings of the 8th International Conference on Language Resources and Evaluation (LREC)*, Istanbul, Turkey, 2012.

Corpus repository: https://github.com/zhichaohu/film-corpus-1
